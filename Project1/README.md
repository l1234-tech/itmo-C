# Project 1 — Основы C++

Раздел с небольшими заданиями на базовые конструкции C++, функции, указатели, обработку чисел и строк.

## Содержание файлов

| Файл | Назначение по содержимому |
|---|---|
| [`main.cpp`](./main.cpp) | Точка входа и примеры вызова функций |
| [`problems.cpp`](./problems.cpp) / [`problems.hpp`](./problems.hpp) | Задачи на цифры числа, обработку последовательностей и агрегирование информации |
| [`pointers.cpp`](./pointers.cpp) / [`pointers.hpp`](./pointers.hpp) | Функции работы с указателями и массивами |
| [`operasion.cpp`](./operasion.cpp) / [`operation.hpp`](./operation.hpp) | Решение квадратного уравнения через дискриминант |
| [`micro_promrams.cpp`](./micro_promrams.cpp) / [`micro_problems.hpp`](./micro_problems.hpp) | Проверка прямоугольного треугольника по длинам сторон |
| [`summa.cpp`](./summa.cpp) / [`summa.hpp`](./summa.hpp) | Сумма цифр трёхзначного числа |

## Что изучается

- Объявление функций и разнесение деклараций в `.hpp` и реализаций в `.cpp`.
- Передача аргументов и возвращение результата.
- Указатели, разыменование и обход диапазона указателей.
- Строки и обработка отдельных символов.
- Математические условия и вычисления.
- Пространства имён и базовая организация кода.

## Сборка

Из этой директории пример команды для сборки нескольких исходников:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp problems.cpp pointers.cpp operasion.cpp micro_promrams.cpp summa.cpp -o project1
```

Состав исходников нужно корректировать под фактические зависимости и выбранный компилятор. В проекте используется специфичная для Windows библиотека `<io.h>`, поэтому `main.cpp` может потребовать адаптации для сборки в Linux или macOS.

## Что проверить при дальнейшей доработке

- В `pointers.cpp` проверить условие завершения функции `str_of_len`.
- Проверить корректность вычисления дискриминанта и обработки отрицательного значения подкоренного выражения.
- Унифицировать написание имён файлов и функций при рефакторинге, сохраняя совместимость с требованиями задания.
- Добавить тесты для пустого диапазона, граничных значений и некорректного ввода.

Эти пункты — направления проверки по текущему коду, а не утверждение о прохождении или непрохождении автоматических тестов.
