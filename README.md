## О проекте

Репозиторий собирает материалы учебного курса в одном месте. Внутри разделов сохранены исходные файлы решений и заголовочные файлы C++.

## Язык и инструменты

- **Язык:** C++
- **Компилятор:** GCC, Clang или MSVC с поддержкой используемого стандарта C++
- **Организация кода:** файлы реализации `.cpp` и заголовки `.hpp`

## Как скомпилировать

Для простого файла с единственным `main()` можно использовать GCC:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o app
./app
```

Если программа использует несколько файлов реализации, передай компилятору все нужные `.cpp` файлы. Например, из папки `Project1`:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp problems.cpp pointers.cpp operasion.cpp micro_promrams.cpp summa.cpp -o project1
```

Команда служит ориентиром по подключению файлов; фактический состав исходников и ошибки компиляции нужно проверять отдельно. В разных папках есть собственные функции `main()`, поэтому **не компилируй все файлы репозитория в один исполняемый файл**.

## Примечание

Это учебный репозиторий. Оформление и документация не означают, что все решения прошли полное тестирование. При запуске ориентируйся на условие конкретного задания и проверяй граничные случаи.
