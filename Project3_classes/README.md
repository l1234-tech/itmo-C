# Project 3 — Classes and OOP

Раздел посвящён классам C++, инкапсуляции данных, операторам, композиции объектов и простой предметной модели.

## Файлы

- [`main.cpp`](./main.cpp) — демонстрационный сценарий работы с классом `Company` и выплатами.
- [`irr_number.hpp`](./irr_number.hpp) — объявления и реализация классов в пространстве имён `Labs`.
- [`readme`](./readme) — исходная заметка к работе.

## Основные классы

| Класс | Назначение |
|---|---|
| `ComplexNumber` | Комплексное число: действительная и мнимая части, модуль, степень и арифметические операторы |
| `Vector` | Трёхмерный вектор: координаты, длина, сложение, вычитание и скалярное произведение |
| `Polynom` | Заготовка класса для работы с полиномом |
| `Promise` | Объект, представляющий обязательство по выплате |
| `Employee` | Сотрудник и связанное с ним обязательство |
| `Director` | Директор как специализированный сотрудник |
| `Company` | Компания с балансом, директором, сотрудниками и логикой выплаты зарплат |

## Что демонстрирует проект

- Инкапсуляцию состояния через поля и публичные методы.
- Конструкторы и значения по умолчанию.
- Наследование: `Director` от `Employee`.
- Композицию и совместное владение объектами через `std::shared_ptr`.
- Перегрузку арифметических операторов.
- Разделение интерфейса и демонстрационного кода.

## Сборка

Из этой директории:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o project3
```

Запуск:

```bash
./project3
```

## Что проверить при дальнейшей доработке

- Обработку деления комплексного числа на ноль.
- Корректность поведения `pow()` для больших показателей и оценку стоимости рекурсивного умножения.
- Единый стиль именования методов и полей.
- Состояние выплат при нескольких последовательных вызовах `fulfillPromise()`.
- Реализацию и тестирование метода `Polynom::at()`, если он требуется заданием.
