# Project 2 — Homework

Домашние задания на работу с числами, циклами, массивами, строками и функциями на C++.

## Файлы

- [`main.cpp`](./main.cpp) — запускает упражнение через `ex_14::ex_14()`.
- [`exercise_5_14.hpp`](./exercise_5_14.hpp) — объявления функций для упражнений.
- [`exercise_5_14.cpp`](./exercise_5_14.cpp) — реализации упражнений.
- [`readme`](./readme) — исходная заметка к работе.

## Темы, встречающиеся в решениях

- Подсчёт элементов и обработка последовательностей.
- Поиск минимума и максимума.
- Числа Фибоначчи и делимость.
- Работа со строками и заменой символов.
- Векторы STL и алгоритмы обхода.
- Нахождение наибольшего общего делителя (НОД).

## Сборка

Из этой директории:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp exercise_5_14.cpp -o project2
```

Запуск:

```bash
./project2
```

В Windows исполняемый файл обычно запускается как `project2.exe`.

## Как устроен запуск

Текущая функция `main()` запускает `ex_14::ex_14()`. Для запуска другого упражнения нужно изменить вызов в `main.cpp` или временно добавить отдельный тестовый сценарий.

## Что проверить при дальнейшей доработке

- В `ex_5()` проверить оператор сравнения при подсчёте повторений минимального значения.
- В `ex_10()` и `ex_13()` проверить заполнение вектора: `insert` и предварительно созданные элементы могут приводить к лишним значениям.
- Проверить обработку нулевых и отрицательных входных значений там, где это допускает условие.
- Добавить примеры входных данных и ожидаемых результатов к каждому упражнению.

Это список направлений для проверки, а не подтверждение прохождения тестов.
